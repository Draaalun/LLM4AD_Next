# Task Version System

When you adjust parameters and re-run a task, a new version is created automatically.

## How Versions Work

1. Each task starts as a root version.
2. Clicking "Adjust Parameters" on a completed/failed task creates a child version with the same configuration.
3. The new version can be modified and run independently.
4. All versions are shown in the Version Tree in the right panel.

## Version Comparison

1. Click the "Version Compare" button in the right panel.
2. Select at least 2 versions (up to 6) by clicking them.
3. Switch between "Parameters" and "Scores" tabs to compare.
4. Use grouped bar charts or radar charts to visualize score differences.
5. Hold Ctrl/Cmd to multi-select versions.

## Version Operations

1. Click a version in the tree to switch to it.
2. Edit version tags for easy identification.
3. The "Latest" badge marks the most recently modified version.
