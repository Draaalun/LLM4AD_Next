# 全局配置

配置所有项目共享的 LLM 供应商和默认模型设置。

## 添加供应商

1. 在左侧边栏点击「模型供应商」进入管理页面。
2. 点击右上角「添加供应商」按钮。
3. 填写供应商名称，选择供应商类型（如 OpenAI、Anthropic）。
4. 输入 API Key（认证令牌）。
5. 添加一个或多个模型名称 — 输入名称后按 Enter 添加。
6. 可选调整超时时间和最大重试次数。
7. 点击「确定」保存。

## 设置默认模型
![test](/guide/test.png)

1. 在模型供应商页面顶部找到「默认模型配置」区域。
2. 为每个角色（规划器、编码器、报告、其他）选择一个供应商。
3. 选择供应商后，从可用模型中选择一个模型。
4. 新建任务时将自动使用这些默认配置。
