# 任务版本系统

当你调整参数并重新运行任务时，系统会自动创建新版本。

## 版本工作原理

1. 每个任务初始为根版本。
2. 对已完成/失败的任务点击「参数调整」会创建一个继承相同配置的子版本。
3. 新版本可以独立修改和运行。
4. 所有版本显示在右侧面板的版本树中。

## 版本对比

1. 点击右侧面板的「版本对比」按钮。
2. 点击选择至少 2 个版本（最多 6 个）。
3. 切换「参数对比」和「评分对比」标签进行比较。
4. 使用分组柱状图或雷达图可视化分数差异。
5. 按住 Ctrl/Cmd 可多选版本。

## 版本操作

1. 点击版本树中的版本可切换查看。
2. 编辑版本标签便于识别。
3. 「最新」标记表示最近修改的版本。
