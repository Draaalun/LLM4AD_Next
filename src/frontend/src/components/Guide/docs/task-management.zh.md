# 任务管理

在项目中创建、配置、运行和分析演化任务。

## 创建任务

1. 从项目页面进入一个项目。
2. 在左侧任务列表面板点击「新建任务」。
3. 输入任务名称，可选择一个模板。
4. 点击「确定」创建任务。

## 配置参数（分步指引）

新任务会自动进入配置向导，请按以下步骤操作：

### 第一步：数据准备

上传所需文件（适应度函数、数据集）。点击「选择目录上传」选择文件夹，勾选需要上传的文件后确认。上传后可以编辑文件内容。

### 第二步：LLM 供应商

为规划器和编码器角色选择供应商和模型。如果不设置，将使用系统默认配置。也可以点击「供应商配置」跳转到全局供应商设置。

### 第三步：评估器

配置适应度评估方式。设置评估函数入口、超时时间和其他评估参数。

### 第四步：进化算法

选择进化算法类型（如岛屿模型）。调整种群大小、迭代次数、选择策略等超参数。

### 第五步：代码生成

配置代码生成策略、Prompt 模板和编码器相关参数。

### 第六步：高级组件

配置内存管理、日志记录、工作区路径和版本控制。通常使用默认值即可。

### 第七步：参数确认

查看完整的 YAML 配置。可以直接编辑、导入/导出 YAML 文件。点击「提交运行」启动任务。

## 运行任务

1. 配置参数后，在确认步骤点击「提交运行」。
2. 任务进入「等待中」然后「运行中」状态。
3. 在主面板实时观看演化仿真过程。
4. 使用底部进度条在不同世代之间导航。
5. 点击右侧面板的「停止运行」可中止任务。

## 查看参数、结果与日志

1. 点击右侧面板的「查看参数」查看只读配置。
2. 切换到右侧面板的「运行日志」标签查看实时日志。
3. 点击可视化图中的节点查看算法详情、适应度分数和谱系信息。
4. 使用趋势分析面板追踪各世代的分数变化。

## 洞察报告

1. 切换到主内容区的「结果洞察」标签。
2. 选择报告类型：整体总结、节点对比、链路分析或最优算法分析。
3. 选择所需的节点（根据报告类型不同而异）。
4. 可选择特定的供应商/模型用于报告生成。
5. 点击「生成报告」等待 AI 生成分析结果。
